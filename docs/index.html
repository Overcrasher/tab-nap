Tab Nap

Let idle tabs sleep

Tab Nap is a free tab suspender for Chrome. It puts idle tabs to sleep using Chrome's own tab discarding, so you get memory back without ever losing a tab.

Coming soon to the Chrome Web Store

Free, no ads, no accounts. Works in Chrome.

How it works

  1. Idle tabs napAfter 30 minutes without use (you can pick 5 to 120), a tab is put to sleep. It keeps its place, title and address.
  2. Nothing important is touchedThe tab you are looking at, pinned tabs, tabs playing sound, tabs still loading and sites on your whitelist are never napped. With the optional typing protection, tabs where you have typed something are left alone too.
  3. Wake any tab with a clickClick a sleeping tab and Chrome reloads it where you left it. The popup lists what is asleep, shows an estimate of the memory freed and how many tab-hours Tab Nap has napped.

Native discarding only

Tab Nap never replaces a tab with a custom "suspended" page. It only asks Chrome to discard the tab, which is how Chrome saves memory itself, so removing Tab Nap can never leave you with broken tabs. The optional typing protection asks for access to sites only if you turn it on, and it only learns a yes/no flag per tab, never what you typed.

Private by design

Everything stays on your device. There are no ads, no tracking and no accounts, and the extension makes no network requests. Tab Nap stores settings and counters, and only a yes/no flag per tab for unsaved typing, never field contents. It is open source, so you can check for yourself. Read the full privacy policy.

Install

Tab Nap will be available from the Chrome Web Store. Developers can already load the source unpacked from GitHub.

Support

Tab Nap is free. If it helps you, you can optionally make a one-time contribution, or support it monthly, through Stripe. The option appears only at milestones of napped tab-hours, and you can turn it off at any time.
