Welcome to Tab Nap

Idle tabs go to sleep, memory comes back, and no tab is ever lost.

Try it now

  1. 1Leave a few tabs idle. After 30 minutes they nap and free memory.
  2. 2Right-click any page and choose "Nap this tab now" to try it right away.
  3. 3Turn on "Protect tabs with unsaved typing" so a half-written message is never put to sleep.

Chrome will ask for permission to see which tabs you type in. Tab Nap never reads what you type: it only learns that a tab has typing in it.

Good to know

Tab Nap uses Chrome's own tab discarding. A napping tab keeps its address and wakes up when you click it. Everything stays on your device. No account, no tracking, no ads.

Pin it: click the puzzle icon in the toolbar, then the pin next to Tab Nap.
