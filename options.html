    Unsaved typing protection

    How it works: when on, a tiny script in each page notices that you typed into a text box and tells Tab Nap "this tab has typing in it". It never reads, stores or sends what you type, and ignores password fields. Such tabs are left awake until the page is reloaded or closed. When off, Tab Nap cannot see forms, so a tab with a half-written message can still be put to sleep. Chrome restores the tab when you return, but typing that was never saved may be lost.

    Memory estimate

    Used only for the "saved" figure in the popup. It is an estimate: napping tabs times this number. Between 50 and 500.
